# Cerca-Volumetrica-3d
🛡️ Hardware y software libre (CERN-OHL / GPLv3) de contención volumétrica 3D ética para mascotas. Combina radar mmWave + UWB con Edge AI (&lt;50 ms) para predecir saltos y guiar con estímulos bioacústicos y olfativos sin choques eléctricos. Modelo "Canasta Básica" (~$115 USD) con 100% de remanentes destinados a rescate animal.
